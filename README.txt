TOPPER JOURNAL - APP PACKAGE

A) NETLIFY PAR PUBLISH
1. netlify.com -> login -> "Add new site" -> "Deploy manually".
2. Is zip ko unzip karke poora folder drag-drop karo. Link milega (xyz.netlify.app).
3. Update ke liye: wahi site -> Deploys -> naya folder drop (naya site mat banao).

B) PHONE ME APP JAISA INSTALL (sabse aasaan)
Android Chrome: link kholo -> "Install app" (ya app ke More tab me "App install karo").
iPhone Safari: Share -> Add to Home Screen.
Icon long-press karne par shortcuts bhi milte hain (Study, Test, Galti, Timer).

C) ASLI APK BANANA (free)
1. Site Netlify par live karo.
2. pwabuilder.com kholo -> apna link daalo -> Start.
3. "Package for stores" -> Android -> Generate -> zip download.
4. Zip me .apk file hoti hai: phone me bhejke install karo (Unknown sources allow).
5. PWABuilder ek assetlinks.json deta hai. Use site me ".well-known/assetlinks.json" ke roop me upload karo
   (taaki APK me browser bar na dikhe), aur site dobara deploy karo.

CLASS 9 / CLASS 10
App me upar "Class ⇄" se class badal sakte ho. Dono ka data alag save hota hai.
Class 9 me Syllabus tab -> "chapters add karo" se textbook ki index paste karo.
Backup har class ka alag hota hai (us class par jaakar backup lo).

NOTE: Data har phone me alag save hota hai. App me More -> Goals & Rules -> Backup copy karke rakho.
